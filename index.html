3 · Installer le service dans votre Google Sheet (à faire une seule fois)
a. Ouvrez votre fichier GESTION ARABIAN TOURS → menu Extensions → Apps Script.
b. Effacez le contenu affiché, collez le script ci-dessous (bouton copier).

d. Cliquez Déployer → Nouveau déploiement → type Application Web → exécuter en tant que moi → accès Tout le monde → Déployer.

Pourquoi « Tout le monde » ? Sans cela, le navigateur ne peut pas appeler le service. La protection est assurée par le jeton secret : sans lui, le service refuse de répondre. Le script ne renvoie d'ailleurs que les totaux par jour — jamais vos lignes de facturation détaillées. Choisissez un jeton long et ne le partagez pas.

📊 Import Excel F Corner — Multi-feuilles & Dépenses

      
    


    

      

        📋 Architecture du fichier Excel :

        🅰 Saisies quotidiennes (Section A) : 1 feuille = 1 jour. Chaque feuille contient les cellules Total CA, TPE, GLOVO. Le nom de la feuille (ex : 05-05-2026) ou une cellule Date est utilisée pour la date.

        🅱 Dépenses consolidées (Section B) : 1 seule feuille avec toutes les dépenses. Colonnes : Date · Catégorie · Sous-catégorie · Montant · Mode · Fournisseur.

        ⚡ Auto-sync : après import des dépenses, le champ Dép. esp. de chaque jour sera automatiquement recalculé depuis la somme des dépenses cash de ce jour.

📥 Import Wafa Caisse — Auto-conversion hebdomadaire

      
    


    
    

      

        📋 Mode d'emploi :

        1️⃣ Connectez-vous à Wafa Caisse

        2️⃣ Affichez le tableau de vos quittances (1 jour, 1 mois, ou plus)

        3️⃣ Sélectionnez le tableau (Ctrl+A) → Copiez (Ctrl+C)

        4️⃣ Collez ci-dessous (Ctrl+V) → cliquez « 📥 Importer »
      

    


    
    

      
📁 Charger le fichier — méthode recommandée

      

        Le fichier entier est lu, filtres Excel ignorés. Un copier-coller ne transmet que les lignes visibles :
        si un filtre est actif, la majorité de vos quittances est perdue sans avertissement.
      

      

        

        

      

      

    


    
    

      📋 Ou coller les données manuellement
      
    


    
    

      

        🤖 Traitement automatique :

        ✓ Détection auto colonnes : Date · Attestation · CATEGORIE (= branche) · Prime client · Net Compagnie · ETAT QUITTANCE

        ✓ Toutes les branches : AUTO · ACCIDENTS CORPORELS · ACCIDENTS DE TRAVAIL · FLOTTE · RISQUES DIVERS

        ✓ Commission = Prime client − Net Compagnie (calcul réel par quittance)

        ✓ Agrégation par semaine ISO + branche : 1 saisie hebdo au lieu de N quotidiennes

        ✓ Re-import intelligent : quittance connue → mise à jour de l'état (IMPAYÉE→RÉGLÉE), pas de doublon

        ✓ Auto-link N-1 : si vous importez 2026, les semaines 2025 seront utilisées comme comparaison automatique
